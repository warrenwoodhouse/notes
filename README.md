# notes
A note taking Progressive Web Application that I’ve created that lets you save private notes and open them later safely and securely.

# install
[CLICK HERE](https://warrenwoodhouse.github.io/notes) to visit the website then select **SHARE** on your browser on your phone or device then select **ADD TO HOME SCREEN** to add the app on your Home Screen on your phone or device.

Unfortunately, it is a <span title="Progressive Web Application, a type of software application on the phone that acts as a type of non-installed shortcut which has limited flexibility.">PWA</span> app which means it can’t be accessed while offline.
